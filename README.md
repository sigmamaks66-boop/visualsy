# Neon Visuals (Fabric 1.21.11, tylko klient)

Chiński kapelusz, ślad, efekty trafienia i zabicia gracza, neonowy celownik, znak wodny.
Wszystko to cząsteczki i HUD po Twojej stronie, nic nie jest wysyłane do serwera.
Menu: komenda `/visuals`. Config: `config/neonvisuals.json`.

Budowanie: `gradle build` -> `build/libs/neonvisuals-1.0.0.jar` (albo przez GitHub Actions).
